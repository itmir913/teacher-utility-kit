학교생활기록부 에디터

학생 명렬표 등록부터 영역 구성, 활동 생성, 생기부 작성, 내보내기까지.
생기부 작성 도우미로서, 아래 순서대로 진행하면 학생별 학교생활기록부 문장을 손쉽게 완성할 수 있습니다.

🚀 전체 워크플로

학교생활기록부 생성부터 나이스(NEIS) 업로드용 엑셀 내보내기까지 전 과정이 직관적으로 구성되어 있습니다.

Step 0

새 프로젝트 시작

작업할 새로운 학교생활기록부 파일(DB)을 생성합니다. 모든 데이터는 외부 전송 없이 선생님의 PC에만 안전하게 오프라인으로 보관됩니다.

Step 1

학생 등록 및 관리

학년, 반, 번호, 이름을 입력하여 기본 학생 명부를 생성합니다. 기존에 사용하시던 엑셀 파일(.xlsx, .csv)을 연동해 전체 명렬표를 클릭 한 번으로 간편하게 불러올 수 있습니다.

Step 2

생기부 영역(Area) 구성

자율활동·진로활동·동아리활동 및 교과목 세특 등 생기부의 큰 뼈대가 되는 '영역'을 생성합니다. 각 영역별로 나이스(NEIS) 기준에 맞춘 최대 바이트(Byte) 제한을 설정할 수 있습니다.

Step 3

세부 활동(Activity) 생성

각 영역에 포함될 구체적인 세부 활동(수행평가, 프로젝트, 학급 행사 등)을 항목별로 생성합니다. 여기서 작성된 세부 활동들이 모여 최종적으로 학생의 훌륭한 생기부 문장으로 완성됩니다.

Step 4

생기부 내용 작성

학생별·활동별로 구성된 직관적인 격자 화면에서 생기부를 편안하게 입력하세요. 실시간으로 바이트 수를 계산하여 분량 조절이 매우 편리합니다. 입력 즉시 자동 저장되며, 셀별 History로 소중한 문장을 버전별로 보관하고, 스냅샷으로 전체 데이터를 원하는 시점으로 언제든 되돌릴 수 있어 작업이 더욱 안전해집니다.

Step 5

나이스(NEIS) 입력용 엑셀 내보내기

작성이 완료된 학생의 생기부를 나이스 양식에 맞춘 엑셀 파일로 자동 추출합니다. 추출된 파일을 나이스에 업로드하여 생기부 업무를 빠르고 완벽하게 마무리하세요!

🧩 데이터 구조는 어떻게 되나요?

생기부의 각 항목을 영역(Area)이라고 부릅니다. 그 안에 학생이 실제로 참여한 개별 활동(Activity) 여러 개를 담아 하나의 문장 묶음을 완성합니다.

👩‍🏫 대상별 맞춤 활용 가이드

역할에 맞게 프로그램을 100% 활용해 보세요.

담임교사용

활동 취합 및 관리에 최적화

담임교사는 자율활동 · 진로활동 영역을 병합하고 검수해야 합니다. 지도교사들이 작성한 엑셀 데이터를 가져오기(Import) 하여, 초과된 바이트를 한눈에 파악하고 효율적으로 분량을 조절하세요.

영역 (Area) 구성 자율활동, 진로활동…
세부 활동 (Activity) 체육대회, 체험학습, 상담기록…
활용 팁:
바이트 초과 시 해당 셀이 붉은색으로 즉시 강조되므로, 길이를 줄여야 하는 학생을 직관적으로 찾아낼 수 있습니다.
교과교사용

세특 작성에 최적화

교과교사는 담당 과목별 세부능력 및 특기사항(세특)을 집중적으로 작성합니다. 수행평가, 수업 참여도, 프로젝트 등 평가 요소들을 세부 활동(Activity)으로 만들어 관리하세요.

영역 (Area) 구성 교과세특(프로그래밍, 인공지능기초 등 과목명)
세부 활동 (Activity) 첫 번째 수행평가, 두 번째 수행평가, 수업 태도…
활용 팁:
엑셀 스프레드시트와 유사한 격자형 인터페이스를 제공하여, 여러 학급과 학생의 세특을 화면 전환 없이 한 번에 연속해서 작성하기 편리합니다.

📋 단계별 상세 사용법

역할에 맞는 순서를 따라 처음부터 끝까지 설정해 보세요.

1

담임 학급 학생 명단 등록

왼쪽 메뉴에서 학생(Students) 탭을 누르세요. 오른쪽 위 일괄 추가 버튼을 클릭한 후, 담임 학급 학생 전원의 학년 · 반 · 번호 · 이름이 담긴 엑셀 파일을 불러옵니다. 출석부(명렬표)를 엑셀로 저장한 파일을 그대로 쓰면 됩니다.

2

생기부 영역 만들기

왼쪽 메뉴에서 영역(Area) 탭을 누르세요. 영역은 생기부 항목 하나에 해당합니다. 오른쪽 위 + 영역 추가 버튼으로 1반 자율활동, 1반 진로활동처럼 영역을 하나씩 만드세요. 영역을 만든 뒤 학생 배정 버튼을 눌러 우리 반 학생 전원을 체크하고 저장합니다.

3

세부 활동 등록

왼쪽 메뉴에서 활동(Activity) 탭을 누르세요. 오른쪽 위 + 활동 추가 버튼으로 각 영역 안에 들어갈 세부 활동을 등록합니다. 예를 들어 1반 자율활동 영역에는 학급자치회, 스포츠데이, 수학여행처럼 실제 자율활동에 들어가는 세부 활동이 들어갑니다. 활동을 추가할 때 어느 영역에 포함될지 선택해 연결합니다.

4

생기부 작성

왼쪽 메뉴에서 생기부 작성(Write) 탭을 누르세요. 상단 드롭다운에서 작성할 영역을 고르면 학생 목록과 활동 열이 표 형태로 펼쳐집니다. 각 칸에 학생별 내용을 바로 입력하면 됩니다.

1

담당 교과별 학생 명단 전체 등록

왼쪽 메뉴에서 학생(Students) 탭을 누르세요. 오른쪽 위 일괄 추가 버튼을 클릭해 담당 교과를 수강하는 모든 학생의 명단을 불러옵니다. 분반이 여러 개라도 일단 전체를 한꺼번에 등록하세요. 어느 분반인지는 다음 단계에서 나눕니다.

2

교과(분반)별 영역 만들기

왼쪽 메뉴에서 영역(Area) 탭을 누르세요. 1개 영역 = 교과(분반) 1개입니다. 오른쪽 위 + 영역 추가 버튼으로 교과명을 입력합니다. 분반이 여러 개라면 프로그래밍 A반, 프로그래밍 B반처럼 분반 수만큼 영역을 만드세요. 만든 영역마다 학생 배정 버튼을 눌러 해당 분반 학생만 체크하고 저장합니다.

3

세특 요소 등록

왼쪽 메뉴에서 활동(Activity) 탭을 누르세요. 오른쪽 위 + 활동 추가 버튼으로 세특에 들어갈 평가 요소를 활동으로 등록합니다. 수행평가1, 수행평가2, 수업태도처럼 세특을 이루는 요소를 항목별로 하나씩 만들고, 어느 교과(영역)에 포함할지 선택합니다.

4

세특 작성

왼쪽 메뉴에서 생기부 작성(Write) 탭을 누르세요. 상단 드롭다운에서 작성할 교과(분반) 영역을 고르면 해당 분반 학생 목록과 평가 요소 열이 표 형태로 펼쳐집니다. 각 칸에 학생별 세특 내용을 바로 입력하면 됩니다.

공통

함께 활용할 수 있는 기능

가져오기(Import)

이미 엑셀로 작성한 생기부가 있다면 가져오기(Import) 탭에서 본 프로그램으로 불러올 수 있습니다. A타입 · B타입 두 가지 양식을 지원하며, 양식 형식이 궁금하다면 예시 다운로드 버튼을 눌러 다운받아 확인하세요.

텍스트 치환(Replace)

텍스트 치환(Replace) 탭에서 특정 단어나 문구를 전체 학생의 생기부에서 한 번에 찾아 바꿀 수 있습니다. 여러 학생에게 반복 사용된 표현을 일괄 수정할 때 유용합니다.

유의어 점검(Inspect)

유의어 점검(Inspect) 탭에서 학교생활기록부에 사용이 제한된 어휘를 자동으로 탐지하고, 적절한 대체 표현을 확인할 수 있습니다. 제출 전 최종 검수에 활용하세요.

체크리스트(Checklist)

체크리스트(Checklist) 탭에서 어떤 학생이 무슨 활동에 참여했는지를 엑셀 파일로 내보내기할 수 있습니다. 단면 인쇄하여 생기부 점검때 활용하세요. 누락 없이 생기부 작성을 마무리할 수 있도록 도와줍니다.

💾 날아갈 걱정 없는 완벽한 저장 및 복구

작성 중인 소중한 생기부 데이터, 단 한 글자도 잃어버리지 않도록 강력한 보호 기능 3가지를 제공합니다.

입력 즉시 자동 저장

글자를 타이핑하는 매 순간순간 데이터베이스에 즉시 저장됩니다. 예기치 못한 컴퓨터 종료나 오류가 발생해도 데이터 유실 걱정 없이 안심하고 작성에만 집중하세요.

버전 히스토리

작성한 생기부 문구가 마음에 들면, 지금 버전을 즉시 저장하세요. 버전 히스토리가 선생님의 생기부 문장을 과거부터 누적하여 모든 변경사항을 꼼꼼하게 추적합니다.

타임머신 스냅샷

현재 작성된 생기부 문장 전체를 찰칵하고 사진 찍듯 스냅샷으로 남기세요. 대대적인 내용 수정을 하더라도 언제든지 마음 편하게 저장해둔 과거의 시점으로 되돌아올 수 있습니다.

철저한 보안 및 이중 백업 장치

모든 데이터는 선생님의 PC에만 안전하게 보관됩니다.

이 프로그램은 어떤 학생 정보도 외부 서버로 전송하지 않습니다. 모든 데이터는 로컬 컴퓨터의 .db 파일에만 저장되므로 보안 걱정 없이 안심하고 사용하세요.

위에서 설명된 3가지 보호 방식은 모두 하나의 DB 파일 내에서 안전하게 작동합니다. 하지만 예기치 못한 오류로 DB 파일 자체가 완전히 손상될 경우를 대비해, 프로그램을 열 때마다 기존 파일을 복사하여 .db.backup 파일을 자동 생성하는 강력한 이중 백업 장치가 마련되어 있습니다.

DB 파일 복구 방법

기존 DB 파일이 열리지 않거나 손상된 경우, 아래 방법으로 마지막 실행 시점의 데이터를 즉시 살릴 수 있습니다.

  1. 프로그램을 완전히 종료합니다.
  2. 손상된 .db 파일을 삭제합니다.
  3. .db.backup 파일의 이름 끝에서 .backup 부분을 지웁니다.
  4. 프로그램을 다시 실행합니다.

⚙️ 생기부 작성에 필요한 모든 것, 자체 내장

이 프로그램은 단순한 입력기가 아닙니다. 교사들의 업무 부담을 줄여주는 강력한 보조 도구를 프로그램 하나에 모두 담았습니다. 별도의 외부 프로그램 없이 고품질의 생기부를 완성하세요.

유의어 점검

학교생활기록부 일괄 점검 프로그램의 작동 로직을 내장하여, 작성 단계에서부터 스마트한 유의어 점검이 가능합니다.

강력한 텍스트 일괄 치환

특수문자, 맞춤법 오류, 혹은 특정 기재 금지어구를 일일이 찾아 바꿀 필요가 없습니다. 클릭 몇 번으로 전체 학생의 기록을 한 번에 수정합니다.

누락 방지 체크리스트

각 학생별로 반드시 기재해야 할 필수 활동이나 평가 요소가 빠지지 않았는지 체크리스트 엑셀을 다운로드받을 수 있습니다.
