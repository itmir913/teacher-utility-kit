진학상담 프로그램(대교협)
서버 자동 재시작 배치파일

대교협 서버가 예기치 않게 종료되더라도, 주기적으로 상태를 감시하여 즉시 서비스를 재시작해주는 자동화 스크립트입니다.

배치파일 다운로드 (.zip)

💻 실행 화면 및 로그

대교협 서버 다운을 감지하고 자동으로 복구하는 과정을 실시간으로 보여줍니다.

tomcat8.exe 종료를 감지하고 KCUE_WAS 서비스를 즉각 재시작하는 모습

🚀 사용 및 설정 가이드

바탕화면에서 직접 배치 파일을 관리자 권한으로 실행하거나, 작업 스케줄러로 완전 자동화할 수 있습니다.

기본 사용법 (수동 실행)

압축을 푼 뒤 나오는 auto_restart_batch_daegyohyeop.bat 파일을 바탕화면 등 편한 곳에 두고 사용합니다.

주의: 관리자 권한 필수

서비스(KCUE_WAS)를 시작/중지하려면 권한이 필요합니다. 반드시 파일을 우클릭하여 [관리자 권한으로 실행]을 눌러주세요.

  • 실행 시 검은 명령 프롬프트(CMD) 창이 켜진 상태로 유지됩니다.
  • 5초 주기로 서버 상태를 확인하므로 창을 닫지 마세요.
추천 설정

완전 자동화 (작업 스케줄러 등록)

이 배치파일을 작업 스케줄러에 등록해두면, 컴퓨터 부팅 후 로그온할 때마다 관리자 권한으로 자동 실행되어 관리자가 전혀 신경 쓸 필요가 없습니다.

등록 방법
  1. 배치파일(.bat)을 삭제되지 않을 안전한 곳(예: 바탕화면 등)에 보관합니다.
  2. Windows 검색창에 '작업 스케줄러'를 검색하여 실행합니다.
  3. 우측 작업 메뉴에서 [작업 만들기...]를 클릭합니다.
    (※ '기본 작업 만들기'가 아닙니다)
  4. [일반] 탭: 이름을 임의로 입력하고, '사용자가 로그온할 때만 실행' 선택, 하단의 ☑ 가장 높은 수준의 권한으로 실행을 체크합니다.
  5. [트리거] 탭: 새로 만들기를 눌러 작업 시작을 '로그온할 때'로 설정하고, 고급 설정에서 '작업 지연 시간: 30초'를 선택합니다.
  6. [동작] 탭: 새로 만들기 - 동작: 프로그램 시작, 프로그램/스크립트 찾아보기에서 보관해둔 배치파일(.bat)을 찾아 선택합니다. 인수 추가나 시작 위치는 작성하지 않습니다.
  7. [설정] 탭: ☐ 다음 시간 이상 작업이 실행되면 중지 항목의 체크를 반드시 해제합니다. (감시가 중간에 꺼지지 않도록 하기 위함)

확인을 누르고 저장하면 설정이 완료됩니다. 다음 부팅 시점부터 알아서 서버를 감시합니다!

⚙️ 작동 원리 및 상세 정보

작동 원리 (로직)

  • tasklist 명령어를 통해 tomcat8.exe 프로세스가 현재 실행 중인지 5초마다 확인합니다.
  • 프로세스가 목록에서 사라지면(서버 다운), 대교협 서버 서비스인 KCUE_WAS를 즉시 중지(net stop)합니다.
  • 안전한 재시작을 위해 3초 대기 후, KCUE_WAS 서비스를 다시 시작(net start)하여 서버를 정상화합니다.
