Teacher Utility Kit

진학결과 분석기

과년도 대입 결과 엑셀을 올려
선배들의 지원·합격 결과를 대학·전형별로 요약하고 학생별로 살펴봅니다.
설치 없이 브라우저에서 바로 씁니다.

상담 화면에 띄워도 되도록, 이름과 학번은 익명 ID를 만드는 순간에만 쓰고 바로 버립니다.
모든 처리는 브라우저 안에서 끝나고, 서버로는 아무것도 보내지 않습니다.

웹에서 바로 사용하기 오프라인 PC 버전

지원 형식 .xlsx .xls .zip  ·  여러 해의 파일을 한꺼번에 올릴 수 있습니다

📊 무엇을 볼 수 있나요

진학결과 파일을 불러오면 아래 화면에서 바로 상담할 수 있습니다.

지원 결과 목록표

  • 여러 해의 지원 건을 한 표에 모아 익명 상태로 확인
  • 머리글을 누를 때마다 정렬 기준이 쌓이는 다중 정렬 (①②③ 표시)
  • 열 순서 변경·너비 조정·숨기기·고정으로 원하는 열만 보기
  • 정렬·필터·열 구성은 새로고침해도 그대로 유지

대학×전형 요약표

  • 지원 건을 대학·전형별로 묶어 한눈에
  • 지원·학생·합격·불합격 인원을 함께 집계
  • 보기 전환 한 번으로 목록표와 오가며 필터는 그대로

필터와 검색

  • 고3 년도·대학·지역·계열·전형·결과로 좁히기
  • 걸린 필터는 칩으로 표시되고 하나씩 해제
  • 여러 낱말을 넣으면 모두 포함한 건만 찾는 검색

학생별 지원 결과

  • 행을 누르면 그 학생의 전체 지원 이력
  • 내신·수능 성적을 타일로 함께 확인
  • 지원 건마다 합·불 띠와 학년도 배지가 붙은 카드

늘 보이는 요약 띠

  • 지원·학생·합격·충원합격·불합격·합격률을 한 줄로
  • 합격률의 분모가 무엇인지 문장으로 함께 표시
  • 결과는 색과 함께 ● △ ✕ 모양으로 구분

여러 해 쌓아 두기

  • 익명 자료를 이 브라우저에 보관해 다음 상담 때 그대로
  • 새 해가 되면 그해 파일만 추가로 올리기
  • 파일 단위로 되돌리고, 같은 파일은 교체할지 추가할지 선택

📋 불러올 수 있는 파일

열은 머리글 이름으로 해석하므로, 양식이 조금 바뀌어도 그대로 읽습니다.

나이스 대입제공현황조회

대입전형 → 제공현황조회 → 제공현황진행상황조회 → [엑셀내려받기]

대교협 수시진학관리

진학관리 → 수시진학관리 → [엑셀 다운로드]

학년 전체 관리자가 전체 학급을 선택하고 검색한 뒤 내려받습니다.

쎈(SEN)진학

데이터관리 → 수시지원결과처리 → 오른쪽 [엑셀]

3학년 전체는 학교 쎈진학 관리자 계정으로 받습니다. 담임 계정은 자신의 학급만 열람됩니다.

이 도구는 학년도가 아니라 고3 년도(학생이 고3이었던 해, 학년도 − 1)로 셉니다. 파일 이름이나 내용에서 추정한 값은 제안일 뿐이니, 파일마다 고3 년도를 직접 확인해 확정해 주세요.

🔒 상담 화면에 띄워도 되도록

진학결과 엑셀에는 개인정보가 들어 있어, 이 부분을 가장 먼저 정했습니다.

이름과 학번을 보관하지 않습니다

익명 ID를 만들 때만 쓰고 바로 버립니다. 화면에도, 브라우저 저장소에도 남지 않습니다.

서버로 아무것도 보내지 않습니다

파일을 읽고 익명화하고 집계하는 일이 전부 이 브라우저 안에서 일어납니다.

내보내기가 없습니다

익명 자료조차 파일로 나가지 않습니다. 보관된 자료는 화면 상단에 늘 있는 데이터 초기화로 지웁니다.
