🚀 두 가지 배포 방식

환경에 맞는 방식을 선택해 손쉽게 구축하세요.

Google Apps Script (서버리스)

별도 서버 없이 Google Drive + Apps Script + Google Sheets만으로 동작합니다. Google 계정 하나로 무료 운영이 가능하며 설정이 매우 간단합니다.

  • 외부 서버·도메인 불필요
  • Google 계정만 있으면 무료 운영 가능
  • 설정 8단계 — 초보자도 따라할 수 있는 가이드 제공
  • 동시접속 최대 30명 (Google Apps Script 제한)

구성 요소

  • Code.gs 백엔드 (검색·인덱싱·캐시)
  • index.html 검색 UI
  • FileIndex Google Sheets 인덱스
  • KeywordLog 키워드 빈도 로그 시트

Node.js + Docker (자체 서버)

Express 백엔드 + SQLite + Nginx를 Docker Compose로 자체 호스팅합니다. 로컬 인덱스와 Drive API 병렬 조회로 더 빠른 응답 속도를 제공합니다.

  • 로컬 SQLite 인덱스로 빠른 검색 응답
  • OAuth 2.0 기반 접근 제어
  • Cloudflare + Nginx Proxy Manager 연동 지원
  • 자체 도메인·서버 필요

구성 요소

  • backend/ Node.js + Express 서버
  • frontend/ Nginx 정적 파일 서버
  • database.sqlite 로컬 인덱스 DB
  • .env 환경변수 설정 파일

⚡ 주요 기능

강력한 검색 엔진과 지능형 캐싱으로 빠르고 정확하게.

Boolean 검색

AND·OR·NOT 연산자와 괄호 그룹으로 복잡한 조건 검색을 지원합니다. 키워드 조합으로 원하는 자료를 정확하게 찾아냅니다.

파일명 + 내용 동시 검색

Drive API v3 fullText contains를 활용하여 파일명뿐 아니라 문서 내부 텍스트까지 전체 검색합니다.

6시간 캐싱 레이어

동일 키워드 재검색 시 Drive API 호출 없이 CacheService에서 즉시 반환합니다. Google API 할당량을 효율적으로 관리합니다.

자동 인덱스 갱신

매일 02:00 전체 재인덱싱, 하루 4회(02:30·07:30·12:30·17:30) 캐시 워밍으로 항상 최신 상태를 유지합니다.

키워드 빈도 로그

검색어를 익명으로 수집하여 캐시 워밍 우선순위에 활용합니다. 3일 미검색 키워드는 매일 03:00 자동 삭제됩니다.

개인정보 보호

익명 검색 키워드만 기록하며 사용자 식별 정보·파일 내용은 일절 수집하지 않습니다. Drive 읽기 권한만 요청합니다.

🔍 Boolean 검색 예시

AND·OR·NOT 연산자와 괄호를 조합하여 원하는 자료를 정확히 찾아냅니다.

입력 예시 동작 설명
예체능 AND 서울 AND 입결 세 키워드 모두 포함된 파일 검색
수학 OR 영어 수학 또는 영어 중 하나라도 포함된 파일
수학 NOT 서울 수학 포함, 서울 미포함 파일 검색
(수학 OR 영어) NOT 서울 괄호로 우선순위 지정 — 서울 제외 수학·영어 파일

📋 단계별 설정 방법

배포 방식에 맞는 순서를 따라 처음부터 끝까지 설정해 보세요.

1

Google 스프레드시트 생성

Google Sheets에서 새 스프레드시트를 생성합니다. 기본 시트 이름을 FileIndex로, 두 번째 시트를 KeywordLog로 지정합니다. 스프레드시트 URL에서 ID를 복사해 두세요.

2

구글 드라이브 폴더 ID 확인

검색 대상 파일이 담긴 루트 폴더를 열고 URL에서 폴더 ID를 복사합니다. https://drive.google.com/drive/folders/[여기가 ID]

3

Apps Script 프로젝트 생성 및 코드 붙여넣기

스프레드시트 메뉴 → 확장 프로그램 → Apps Script를 엽니다. 기본 Code.gs 내용을 모두 지우고 저장소의 src/Code.gs 내용을 붙여넣습니다. HTML 파일을 추가하고 이름을 index로 지정한 뒤 src/index.html 내용을 붙여넣습니다.

4

상수 값 교체

Code.gs 상단의 세 상수를 실제 값으로 교체합니다.

const INDEX_SHEET_ID = 'your_spreadsheet_id';
const FOLDER_ID      = 'your_root_folder_id';
const ADMIN_PASSWORD = 'your_password';
5

Drive API v3 활성화

Apps Script 편집기 왼쪽 사이드바 서비스(+)를 클릭하고 목록에서 Drive API를 선택합니다. 버전을 v3으로, 식별자를 Drive로 유지한 뒤 추가합니다.

6

최초 인덱스 빌드

함수 목록에서 rebuildMetadataIndex를 선택하고 실행 버튼을 클릭합니다. FileIndex 시트에 파일 목록이 채워지면 성공입니다.

7

트리거 설치

setupTriggers를 선택 후 실행합니다. Apps Script 왼쪽 편집기의 트리거 메뉴에서 자동 갱신 스케줄이 등록됐는지 확인하세요.

8

웹앱 배포

Apps Script 편집기 우측 상단 배포 → 새 배포를 클릭합니다. 유형: 웹 앱, 실행 사용자: 나(스크립트 소유자), 액세스 권한: 모든 사용자로 설정하고 배포합니다. 생성된 웹앱 URL을 구성원에게 공유하면 검색을 시작할 수 있습니다.

1

Google Cloud 프로젝트 설정 및 Drive API 활성화

Google Cloud Console에서 프로젝트를 생성하고 API 및 서비스 → 라이브러리에서 Google Drive API를 활성화합니다.

2

OAuth 동의 화면 및 클라이언트 ID 발급

OAuth 동의 화면을 구성하고 사용자 인증 정보 → OAuth 클라이언트 ID를 발급합니다. 승인된 리디렉션 URI에 https://your-domain.com/oauth/callback을 추가합니다. 발급된 JSON 파일을 docker/data/credentials.json으로 저장합니다.

3

저장소 클론

저장소를 클론하고 docker/ 디렉토리로 이동합니다.

git clone https://github.com/itmir913/gdrive-indexr-webapps.git
cd gdrive-indexr-webapps/docker
4

환경변수 설정

.env.example을 복사하여 .env를 생성하고 값을 채웁니다.

FOLDER_ID=your_root_folder_id
ADMIN_PASSWORD=your_password
OAUTH_REDIRECT_URI=https://your-domain.com/oauth/callback
5

빌드 및 실행

Docker Compose로 빌드하고 실행합니다. 로그에서 [INFO] [Server] 포트 3000에서 가동 중 메시지가 확인되면 성공입니다. 브라우저에서 도메인에 접속하면 OAuth 인증 후 자동으로 인덱싱이 시작됩니다.

docker compose up -d --build

⚙️ 아키텍처 & 서비스 스펙

Boolean 파서와 집합 연산 엔진이 Drive API와 결합하여 정확하고 빠른 검색을 실현합니다.

Apps Script 검색 흐름

브라우저 (index.html)
└─ doSearch(query)
└─ tokenize → buildExpressionTree
└─ getFileIdsForKeyword
├─ CacheService 히트 → 즉시 반환
└─ 미스 → Drive API → 캐시 저장
└─ 집합 연산 (AND / OR / NOT)
└─ lookupMetadata → Sheets 조회

서비스 용량 한도

동시접속 (Only GAS) 최대 30명
쿼리 내 키워드 수 5개 이하 권장
활성 캐시 키워드 100개 자동 유지
인덱싱 파일 수 10만 개 이하 권장
