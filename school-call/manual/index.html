선생님 실시간 호출 시스템 구축 가이드

학생들이 교무실 문 앞에서 선생님을 실시간 호출할 수 있는 시스템을 구축하기 위한 가이드입니다. 인터넷이 원활한 환경과 인터넷에 접속할 수 없는 학교 환경 모두에서 작동할 수 있도록 구현되어 있습니다.

01. 데이터 흐름도

이 시스템은 송신부, 릴레이 서버, 수신부의 세 단계로 구성되어 있습니다. 학교 인터넷 환경은 송신 단말과 수신 단말의 1:1 통신을 허용하지 않으므로 중간 브릿지 역할을 해주는 릴레이 서버가 필요합니다.

릴레이 서버를 VPS(클라우드)에 올리면, 전 세계 어디서나 인터넷에 접속할 수 있는 환경에서 언제든지 송수신 가능합니다. 반대로 라즈베리파이 핫스팟 등을 이용하여 로컬 내부 망에 올리면, 인터넷 없는 환경에서도 알림 시스템을 구현할 수 있습니다.

모든 데이터는 AES 암호화 알고리즘을 통해 암호화됩니다. 종단간 암호화(E2EE) 방식이므로 릴레이 서버는 공개된 정보(Room ID)를 제외하면 어떠한 정보도 확인할 수 없습니다.

02. 하드웨어 구성 및 연결

라즈베리파이를 이용하여 본 시스템을 구축하면, 라즈베리파이가 릴레이 서버 역할과 수신부 역할을 동시에 수행할 수 있습니다.

라즈베리파이에 도커(Docker)를 설치하고 릴레이 서버를 올린 다음, 소리가 출력되는 모니터를 라즈베리파이와 연결하면 로컬 백엔드 서버와 수신부를 동시에 수행합니다.

  • 라즈베리파이에 도커(Docker)를 설치하고, docker compose를 이용하여 본 시스템을 설치합니다.
  • 라즈베리파이에서 로컬 핫스팟을 켭니다.
  • 아이패드(송신부)를 해당 핫스팟에 연결하고, 라즈베리파이 IP로 접속하여 송신 단말로 사용합니다.
  • 라즈베리파이에서 브라우저를 열고, 로컬 서버의 수신기 페이지로 접속하여 수신 단말로 사용합니다.

03. Docker 엔진 설치

라즈베리파이 OS에서 아래 명령어를 순서대로 입력하여 Docker 환경을 구축합니다.

# Update Your System
sudo apt update && sudo apt upgrade -y

# Install Docker via Convenience Script
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# Post-Installation (Optional but Recommended)
sudo usermod -aG docker $USER

※ 권한 적용을 위해 반드시 재부팅하거나 로그아웃 후 다시 접속하세요.

04. 케이스별 명령어 실행

공통 사전 준비:

git clone https://github.com/itmir913/teacher-utility-kit
cd teacher-utility-kit/school-call/backend

[CASE A] Relay 모드 (단독 운영)

로컬에서만 사용하거나, VPS 클라우드에 단독으로 올릴 때 사용합니다.

1) Nginx 웹서버를 포함하여 전체 실행할 때:

docker compose up -d --build

2) 이미 구축된 웹서버가 있어 백엔드(릴레이 서버)만 가동할 때:

docker compose up -d school-call --build

[CASE B] Mirror 모드 (하이브리드 운영)

라즈베리파이(로컬)와 클라우드(외부)를 동시 지원해야 할 때 사용합니다.

school-call/backend/.env.mirror 파일을 열고, CLOUD_URL과 MIRROR_SECRET_KEY를 정의하세요. 릴레이 모드로 운영되는 서버의 주소를 입력해야 합니다.

악의적인 공격을 막기 위해, 미러 서버에도 동일한 MIRROR_SECRET_KEY를 정의해야 합니다. 미러 서버와 정상적으로 연결되었는지 여부는 http://localhost:3000 주소로 접속하여 확인할 수 있습니다.

1) Nginx 웹서버를 포함하여 미러 모드로 가동할 때:

MODE_ENV=mirror docker compose up -d --build

2) 백엔드(릴레이 서버)만 미러 모드로 가동할 때:

MODE_ENV=mirror docker compose up -d school-call --build

💡 Mirror Mode의 작동 원리

미러 모드(Mirror Mode)는 로컬 서버가 수신된 모든 신호를 외부의 클라우드 서버로 실시간 복제(Mirroring)하여 이중 전송하는 하이브리드 방식입니다.

  • ✔ 로컬망 내부에서는 인터넷 장애와 상관없이 즉각적인 알림이 보장됩니다.
  • ✔ 외부망에서는 클라우드 미러 서버를 통해 장소에 구애받지 않고 호출을 확인합니다.

05. 시스템 실제 사용 방법

1

수신부 세팅 (라즈베리파이 모니터)

라즈베리파이에 연결된 모니터에서 웹 브라우저를 열고 http://localhost (또는 라즈베리파이 IP 주소)에 접속합니다. 메인 화면에서 [수신부 모드]를 클릭하여 통신 환경을 설정합니다.

✓ Room ID 통신 식별자입니다. 송신부와 동일한 ID를 입력해야 연결됩니다. 이 ID는 공개됩니다.

✓ PIN 번호 메시지 보호를 위한 종단간 암호화(E2EE) 키입니다. 혹시 타인이 동일한 Room ID를 쓰더라도 PIN이 다르면 내용을 열어볼 수 없어 안전합니다.

✓ 수신인 이름 특정 선생님 전용으로 지정하려면 입력합니다. 이 칸을 비워두면 '공용 수신기'가 되어 Room ID로 오는 모든 호출을 알려줍니다.

✓ 기타 설정 알람을 자동으로 닫는 팝업 유지 시간(초)과, 취향에 맞는 7가지 벨소리(딩동댕동, 캐논 느낌, 부드러운 소리 등)를 선택한 뒤 [수신 대기 시작] 버튼을 누릅니다.

2

송신부 세팅 (아이패드/스마트폰)

라즈베리파이의 핫스팟(또는 동일 네트워크)에 연결된 송신용 기기에서 브라우저를 열고 http://[라즈베리파이 IP 주소] 로 접속합니다. 메인 화면에서 [송신부 모드]를 클릭합니다.

✓ Room ID 및 PIN 번호 매칭: 수신부와 정확히 동일한 Room ID와 PIN 번호를 입력하여 암호화 통신을 연결합니다.

✓ 수신인 목록 설정: 송신부 화면에 버튼으로 배치할 호출 대상 선생님들의 이름 목록(예: 김이름, 박이름)을 세팅합니다.

3

실시간 호출 테스트

세팅 완료 후, 송신부(아이패드) 화면에 생성된 선생님 이름 버튼을 터치합니다. 교무실의 수신부 모니터 화면 전체에 시각적인 팝업과 함께 설정한 알림음이 발생하는지 확인합니다. 알림이 정상적으로 뜬다면 완벽하게 구축된 것입니다!
