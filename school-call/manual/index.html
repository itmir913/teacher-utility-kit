Docker 기반 구축 매뉴얼

도커 컴포즈를 활용한 빠른 설치와 안정적인 로컬 네트워크 구성 방법을 안내합니다.

01. 시스템 구조도

⚠️ 네트워크 구축 주의사항

왜 학교 무선망을 사용하지 않나요?

  • 학교 Wi-Fi는 보안 정책상 기기 간 직접 통신(P2P)이 차단된 경우가 많습니다.
  • 수많은 접속자로 인해 응답 속도가 느려져 실시간 제어가 어렵습니다.
  • 외부망 연결 없이 **전용 공유기를 통한 로컬망** 구성을 강력히 권장합니다.

* 전용 공유기를 사용하면 0.01초 이내의 빠른 응답 속도를 확보할 수 있으며, 복잡한 인증 절차 없이 즉시 연결됩니다.

02. Docker Compose 설치

1

docker-compose.yml 작성

제공된 설정 파일을 프로젝트 루트 폴더에 저장합니다.

version: '3.8'

services:
  raspberry-pi-server:
    build: .
    ports:
      - "3000:3000"
    restart: always
    environment:
      - NODE_ENV=production
2

컨테이너 빌드 및 실행

터미널에서 아래 명령어를 입력하여 시스템을 가동합니다.

# 백그라운드에서 실행
docker compose up -d

# 실행 상태 확인
docker compose ps
3

접속 확인

동일한 로컬망에 연결된 기기에서 브라우저를 열고 접속합니다.
http://[라즈베리파이-IP]:3000
