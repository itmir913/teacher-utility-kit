Teacher Utility Kit

모의고사 성적 분석 시스템

진학 프로그램에서 내려받은 성적 파일 하나로
학년 전체 통계부터 학생 개인 리포트까지 만듭니다.
설치 없이 브라우저에서 바로 씁니다.

성적 자료를 다루는 도구인 만큼, 데이터가 기기 밖으로 나가지 않도록 만들었습니다.
파일을 읽는 것부터 리포트를 그리는 것까지 전부 브라우저 안에서 끝납니다.

웹에서 바로 사용하기 오프라인 PC 버전

지원 형식 .xlsx .xls .csv  ·  암호가 걸린 .xlsx도 비밀번호를 넣어 열 수 있습니다

📊 무엇을 볼 수 있나요

성적 파일을 불러오면 아래 분석이 한 번에 만들어집니다.

종합 분석 리포트

  • 전체 인원 기준 주요 지표를 자동 산출
  • 국어·수학·영어 상위 20% 평균 제공
  • 원점수·표준점수·백분위 기준을 버튼 하나로 전환
  • 시험 총평과 학습 전략을 직접 써 넣어 함께 인쇄

성적 분포와 상위권

  • 원점수 합(국어+수학+탐구1+탐구2) 기준 상위 학생 명단
  • 점수 급간별 인원 분포를 표와 그래프로
  • 급간 폭과 표시 인원을 그 자리에서 조절

선택과목 통계

  • 국어·수학·탐구 선택 비율을 자동 집계
  • 과목별 평균 원점수와 평균 등급을 나란히 비교
  • 과목을 누르면 선택한 학생 명단 확인

수능 최저학력기준

  • 2합·3합·4합·5합 조건별 충족 인원 누적표
  • 합에 쓰인 과목이 무엇인지 함께 표시
  • 전교 석차 기준과 학급 기준을 각각 확인

과목별 성적 분포

  • 등급·백분위별 학생 분포를 과목마다
  • 막대를 누르면 그 급간의 학생 명단
  • 학생 행을 누르면 개인 상세 성적과 인쇄

양식 변환 & 내보내기

  • 한 번 불러온 성적을 다른 진학 프로그램 양식으로 변환
  • 프로그램별 열 순서에 맞춰 정렬된 엑셀 파일 생성
  • 보고서 전체를 PDF로 인쇄

서버가 없습니다

업로드하는 곳이 없습니다. 파일을 읽고 계산하고 그리는 일이 전부 브라우저 안에서 일어납니다.

오프라인으로 씁니다
