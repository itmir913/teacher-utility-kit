선발 관리 시스템

교내 학교장추천전형 지원자 점수 계산·순위·추천 관리 도구.
단일 .exe 파일로 내부망에서 바로 실행하세요.

Windows 다운로드 매뉴얼 다운로드
GitHub 저장소 바로가기

내부망 전용 — 모든 데이터는 학교 PC에만 저장됩니다

🔄 전체 워크플로

관리자와 담임교사가 역할을 나눠 순서대로 진행합니다.

1
관리자

전형 환경 설정

  • 학생·학급·담임 계정을 Excel로 일괄 업로드
  • 지원 가능 대학·모집단위·모집 정원 설정
  • 전형요소 점수 기준 설정 — NUMERIC(내신·출결), CATEGORY(수상·활동), MANUAL(직접입력)
라운드 OPEN 담임교사 입력 활성화
2
담임교사

지원자 정보 입력

  • 담당 학급 학생 중 지원자 선택 및 대학·모집단위 등록
  • 내신·출결·봉사 등 전형요소 값 직접 입력
  • 입력 값 기준 예상 점수 즉시 미리보기 (백엔드 계산)
라운드 CLOSED 담임 입력 마감 · 점수 계산
3
관리자

마감 및 점수 계산

  • 마감 전 기초데이터 누락 자동 검증 — 누락 시 오류 표시 후 OPEN 유지
  • 전 지원자 점수 일괄 계산 — Float-Free 정수 연산
  • 지원 현황·순위 확인 및 재오픈(OPEN) 가능
4
관리자

추천·미선발 결정

  • 점수순 정렬 목록에서 추천 대상 클릭 한 번으로 확정
  • 정원만큼 자동 추천도 가능 — 대학별·전체 일괄
  • 동점자가 정원 초과 시 자동 확정을 멈추고 관리자 판단에 맡깁니다
  • 추천하지 않을 지원자는 사유를 적어 미선발 처리 — 사유 없이는 처리되지 않습니다
라운드 FINALIZED 전원 결정되어야 마감 가능 · 되돌릴 수 없음
5
관리자 담임교사

마감 이후

  • 전체 결과 Excel 내보내기 — 추천 여부·점수·순위 포함
  • 담임교사는 담당 학생의 최종 결과 조회
  • 학생이 지원을 포기하면 포기 처리 — 마감된 라운드에서만 가능하며, 빈 자리는 다음 라운드 정원에 반영됩니다
  • 다음 차수가 필요하면 새 라운드를 열어 1~4단계를 반복합니다

👥 역할별 기능 안내

관리자와 담임교사가 각자의 역할에 맞는 화면을 사용합니다.

관리자

전형 전체를 한 화면에서

  • 학생·학급·담임 관리 — Excel 일괄 업로드, 담임 계정도 같은 파일로 함께 생성
  • 대학·모집단위 설정 — 대학·트랙·모집 정원 관리
  • 전형요소 설정 — NUMERIC·CATEGORY·MANUAL 세 가지 유형, 학교 자체 배점 반영. 모집단위마다 배점이 다른 전형요소도 지원
  • 점수 계산·순위 — 마감 후 전 지원자 일괄 계산, 순위 자동 정렬(재학생 우선 선발 가능)
  • 감사 기록 — 누가 언제 무엇을 했는지 자동 기록. 수정·삭제할 수 없습니다
  • 결과 내보내기·백업 — 전체 결과 Excel, 복원 안내문이 포함된 데이터 백업 zip 즉시 다운로드
담임교사

담당 학급 지원자 입력에 집중

  • 지원자 등록 — 담당 학급 학생 중 지원자를 선택해 지원 대학·모집단위 등록
  • 전형요소 값 입력 — 출결·봉사 등 항목별 값 직접 입력
  • 점수 미리보기 — 학생의 예상 점수 즉시 확인
  • 결과 조회 — 라운드 종료 후 학생의 최종 선발 결과 확인
  • 지원 포기 처리 — 마감된 라운드에서 학생의 지원 포기 반영

🚀 시작하기

별도 설치나 서버 운영 없이 3단계로 바로 실행됩니다.

1

최신 버전 다운로드

Releases 페이지에서 최신 버전 파일을 내려받아 원하는 폴더에 압축을 풉니다.

2

exe 실행

principal-candidate-manager.exe를 실행하면 시스템 트레이에 아이콘이 조용히 등록됩니다.
트레이 아이콘을 우클릭 후 열기를 누르거나 http://localhost:8080으로 직접 접속하세요.

3

담임교사 접속 안내

같은 내부망(LAN)에 있는 담임교사는 관리자 PC의 IP 주소로 접속합니다.
예: http://192.168.x.x:8080
포트를 바꾸려면 실행 파일 옆 pcm/config.json의 port 값을 수정하세요.

데이터 경로와 백업: 실행 파일 옆 pcm 폴더에 모든 데이터가 저장됩니다. 백업은 관리자 화면의 업데이트 & 백업 탭에서 내려받으세요 — 프로그램을 켜 둔 채로도 안전한 시점의 사본이 zip으로 만들어지고, 복원 절차를 적은 안내문이 함께 들어갑니다.
data.db 파일 하나만 복사하는 방식은 권장하지 않습니다. 최근 입력이 아직 data.db-wal에 남아 있을 수 있어 그대로 누락됩니다.

⚙️ 설계 원칙

학교장 추천 전형 선발 결과는 학생의 대입 원서 접수에 직접적인 영향을 줍니다. 계산 오류와 데이터 유실을 원천적으로 차단하도록 설계했습니다.

Float-Free

모든 점수는 ×100,000 정수로 저장해 부동소수점 오류를 원천 차단합니다. 0.1점 차이도 정확하게 판별합니다.

Fail-Fast

점수 계산 오류는 즉시 실패로 처리합니다. 잘못된 값이 0으로 대체되는 묵시적 처리는 없습니다.

내부망 전용

외부 서버로 데이터를 전송하지 않습니다. 모든 정보는 학교 PC의 단일 .db 파일에만 저장됩니다.
