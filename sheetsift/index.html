대용량 XLSX·XLS·CSV 파일을 엑셀 없이 열고, 필요한 데이터만 빠르게 찾아보세요. 원본을 건드리지 않는 읽기 전용 뷰어로, 오프라인 앱과 웹 버전을 모두 지원합니다.

📂 지원하는 파일 형식

XLSX·XLS·CSV 파일을 열 수 있습니다.

여러 시트

여러 시트가 있는 엑셀 파일은 왼쪽 목록에서 원하는 시트를 선택하세요.

여러 행의 열 제목

헤더가 시작되는 행과 행 수를 직접 지정할 수 있으며, 헤더를 찾지 못하면 안내해 드립니다.

메모리 안내

파일이 너무 크면 기기의 메모리가 부족해 파일을 열지 못하거나 작업이 중단될 수 있습니다.

🔍 표 탐색과 정렬·필터

많은 데이터 중에서도 필요한 행만 간편하게 추려 보세요.

정렬하기

열 제목을 클릭해 원하는 기준으로 정렬하세요. 여러 열을 차례로 지정해 정렬 순서를 세밀하게 조정할 수 있습니다.

필요한 데이터만 찾기

열마다 검색어를 입력하거나 목록에서 값을 선택해 필터를 적용하세요.

열 너비와 순서 바꾸기

열 경계선을 끌어 너비를 조정하고, 열 제목을 끌어 원하는 순서로 배치하세요.

주요 열 고정하기

왼쪽의 주요 열을 고정하면 가로로 이동해도 해당 열을 계속 확인할 수 있습니다.

가로로 이동하고 인쇄하기

Shift+마우스 휠로 표를 좌우로 이동할 수 있습니다. 현재 화면에 표시된 표도 그대로 인쇄할 수 있습니다.

🔒 개인정보와 파일 보안

파일은 기기 밖으로 나가지 않고, 원본은 그대로 남습니다.

파일을 외부로 전송하지 않습니다

파일을 열고 데이터를 조회하는 작업은 사용 중인 기기 안에서 이루어집니다. 파일을 외부 서버에 업로드하지 않습니다.

원본 파일은 그대로 유지됩니다

SheetSift는 읽기 전용으로 동작합니다. 파일의 내용을 수정하거나 변경 사항을 원본에 저장하지 않습니다.

파일 내용을 따로 보관하지 않습니다

불러온 파일 데이터는 새로고침하면 사라집니다. 언어, 테마, 열 배치 등 화면 설정만 기기에 저장됩니다.
