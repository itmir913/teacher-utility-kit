Teacher Utility Kit

코드 학습지 생성기

수업에 쓸 코드를 붙여넣고 가릴 부분을 드래그하면
학생용 학습지와 정답지가 함께 만들어집니다.
설치 없이 브라우저에서 바로 씁니다.

워드에 코드를 옮겨 붙이고 들여쓰기와 줄 번호를 손보던 일을 없애려고 만들었습니다.
구문 강조와 줄 번호를 유지한 채 A4에 맞춰 인쇄됩니다.

웹에서 바로 사용하기 오프라인 PC 버전

지원 언어 C Python Java JavaScript

✏️ 어떻게 만드나요

코드를 붙여넣고, 가릴 곳을 드래그하면 끝입니다.

1

코드를 씁니다

VS Code와 같은 편집기(Monaco)를 그대로 씁니다. 구문 강조와 들여쓰기가 살아 있어 붙여넣은 코드가 흐트러지지 않습니다.

1  int main() {
2      int total = 10;
3      return 0;
4  }
2

가릴 곳을 고릅니다

가리기 모드에서 코드를 드래그하면 그 자리가 빈칸이 됩니다. 학생용에서는 가려지고, 정답지에서는 원래 내용이 그대로 보입니다.

1  int main() {
2      int total = ____;
3      return 0;
4  }
▬

빈칸

가린 자리에 밑줄이 그어집니다. 답을 직접 써 넣게 할 때 씁니다.

/*

주석

가린 자리를 주석 표시로 바꿉니다. "여기서 무엇을 해야 할까"를 묻는 문제에 맞습니다.

■

숨김

표시를 남기지 않고 지웁니다. 코드 일부를 통째로 다시 쓰게 할 때 씁니다.

🧩 무엇을 만들 수 있나요

한 학습지에 문제를 여러 개, 문제마다 코드 블록을 여러 개 둘 수 있습니다.

네 가지 문제 유형

  • 빈칸 채우기 — 가려진 코드를 채워 넣기
  • 출력 예측 — 실행 결과를 적어 보기
  • 오류 찾기 — 잘못된 부분을 짚어 내기
  • 순서 맞추기 — 흩어진 코드를 제자리로

학생용과 정답지

  • 버튼 하나로 두 화면을 오갑니다
  • 같은 자료에서 뽑으므로 정답이 어긋날 일이 없습니다
  • 문제마다 해설을 따로 적어 둘 수 있습니다
  • 학생용에는 답 쓸 줄을 원하는 만큼 넣습니다

A4 인쇄에 맞춰

  • 1단·2단 배치를 고르거나 코드 길이에 맡깁니다
  • 글자 크기·줄 간격·여백을 조절합니다
  • 줄 번호 자리수를 맞춰 코드 왼쪽 끝이 가지런합니다
  • 브라우저 인쇄로 종이·PDF 어느 쪽이든

저장하고 다시 고치기

  • 학습지를 파일 하나로 저장하고 다시 불러옵니다
  • 다음 학기에는 가릴 곳만 바꿔 다시 씁니다
  • 문제를 복제하고 드래그로 순서를 바꿉니다
  • 눈여겨볼 줄에 강조 표시를 넣습니다

🔒 작성한 내용은 어디로도 가지 않습니다

수업 자료를 다루는 도구라 이 부분을 먼저 정했습니다.

서버가 없습니다

업로드하는 곳이 없습니다. 코드를 쓰고 학습지를 그리는 일이 전부 브라우저 안에서 끝납니다.

오프라인으로 씁니다

PC 버전을 내려받아 압축을 풀고 index.html을 열면 인터넷 없이 그대로 동작합니다.

코드가 공개돼 있습니다

무엇을 어떻게 처리하는지 저장소에서 직접 확인할 수 있습니다.

🚀 시작하기

두 가지 방법 중 편한 쪽을 고르면 됩니다.

1

웹으로 쓰기

접속하면 곧바로 최신 버전입니다. 설치도 로그인도 없습니다. 왼쪽 + 버튼으로 첫 문제를 추가하면 바로 시작합니다.

앱 열기
2

PC에서 쓰기

압축 파일을 받아 풀고 index.html을 엽니다. 인터넷이 닿지 않는 교내망에서도 쓸 수 있습니다.
