Teacher Utility Kit

학교생활기록부
일괄 점검 프로그램

이 프로그램은 PDF 및 Excel(.xlsx) 파일 내에 특정 단어(CSV)가 포함되어 있는지 일괄 검사하는 도구입니다.

최신 버전 프로그램 다운로드 GitHub 저장소 바로가기

📸 프로그램 실행 화면

깔끔하고 직관적인 사용자 인터페이스를 제공합니다.

프로그램의 실제 실행 화면(「📖 사용 방법」 탭)입니다.

🚀 사용자 가이드 (선생님용)

4단계로 쉽게 생기부를 점검할 수 있습니다.

1

검색 기준 설정

생기부 점검에 사용할 금칙어나 기재 불가어 목록이 담긴 CSV 파일을 준비해 주세요.
※ 검색어는 반드시 CSV 파일의 첫 번째 열에 입력되어야 합니다. 프로그램 실행 시 기본 점검 단어 목록을 자동으로 불러옵니다.

단위 학교 맞춤형 설정 (담당 교사 활용 팁)
  • 프로그램 실행 시 _internal 폴더 내 default.csv를 기본 검색어 목록으로 자동 로드합니다.
  • 생기부 담당자가 학교 기준에 맞게 이 파일을 수정하여 배포하면, 전 교직원이 별도 설정 없이 동일한 기준으로 점검할 수 있습니다.
[CSV 파일 불러오기] 버튼을 누르거나 파일을 화면으로 드래그 앤 드롭하세요.
정상 등록 시 상단에 검사할 단어 수가 실시간으로 표시됩니다.
2

검색 대상 파일 추가

「📁 검색 대상 파일」 탭에서 점검할 학생부 PDF 또는 Excel 파일을 추가합니다. 파일을 화면으로 드래그 앤 드롭하여 여러 개를 한 번에 추가할 수 있습니다.
파일은 외부 서버로 전송되지 않고 로컬 PC에서만 처리됩니다.

나이스(NEIS)에서 파일 준비하기
  • Excel: 학급담임 ▷ 학생부 ▷ 학생부 항목별 조회 ▷ [저장] ▷ XLS data
  • PDF: 인쇄 ▷ 프린터 선택 ▷ PDF로 저장
    (※ 텍스트 검색 가능한 원본만 가능, 이미지 스캔본 불가)
3

처리 시작 및 확인

파일 준비가 완료되면 하단의 ▶ 처리 시작 버튼을 클릭합니다.

진행 상황은 「📜 시스템 로그」 탭에서 실시간 확인 가능하며, 처리 중 강제 중단(⛔ 중지)도 가능합니다.
4

결과 파일 활용법

완료 시 원본과 같은 폴더에 output_이 붙은 파일이 생성됩니다.

  • Excel: 우측에 '발견여부/단어' 컬럼 추가 및 해당 행 전체 노란색 강조
  • PDF: 단어에 노란색 하이라이트 추가, 북마크(목차)를 통해 발견 위치로 즉시 이동 가능
