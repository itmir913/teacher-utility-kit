DOMjudge 설치 (Docker Compose)

1. 설치 디렉토리 준비

설치에 필요한 설정 파일들을 보관할 전용 디렉토리를 생성하고 이동합니다.

mkdir -p ~/domjudge && cd ~/domjudge

2. Judgehost 개수 계산

docker-compose.yml을 작성하기 전에 서버의 CPU 코어 수를 확인하고, Judgehost 개수를 결정합니다.

nproc
# 출력 예: 16
# → 사용할 Judgehost 수: 16 - 4 = 12

💡 코어 배분 전략:
모든 코어를 채점에 사용하면 DB(MariaDB)와 웹 서버(Domserver)가 가용 자원을 확보하지 못해 시스템이 느려질 수 있습니다. 따라서 전체 코어 중 4개는 시스템 유지용으로 남겨두고 나머지를 채점기에 할당하는 것이 가장 안정적입니다.
(예: 16코어 서버의 경우 Judgehost 12개 권장)

nproc 명령어의 숫자를 기억해두고, 다음 단계의 docker-compose.yml에서 judgehost의 개수를 조절하면 됩니다. 아래의 예시 파일에는 judgehost가 총 12개 선언되어 있습니다.

3. docker-compose.yml 작성

nano docker-compose.yml 명령어로 아래 설정 내용을 작성합니다. judgehost 서비스의 개수를 조절하되, DAEMON_ID값만 서로 다르게 조절해주세요.

  image: domjudge/judgehost:9.0.0
  restart: always
  privileged: true
  cgroup: host
  depends_on:
    domserver:
      condition: service_healthy
  volumes:
    - /sys/fs/cgroup:/sys/fs/cgroup:rw

x-judgehost-env: &judgehost-env
  DOMSERVER_URL: http://domserver/api
  JUDGEDAEMON_PASSWORD: your_password  # Judgehost API 비밀번호를 확인하고 실제 값으로 변경하세요
  CONTAINER_TIMEZONE: Asia/Seoul

services:
  mariadb:
    image: mariadb:10.11
    container_name: domjudge-mariadb
    restart: always
    environment:
      MYSQL_ROOT_PASSWORD: domjudge_root_pass
      MYSQL_USER: domjudge
      MYSQL_PASSWORD: domjudge_pass
      MYSQL_DATABASE: domjudge
      TZ: Asia/Seoul

      - 13306:3306

      - mariadb-data:/var/lib/mysql

  domserver:
    image: domjudge/domserver:9.0.0

      - mariadb

      - "80:80"

      MYSQL_PASSWORD: domjudge_pass
      MYSQL_DATABASE: domjudge
      MYSQL_ROOT_PASSWORD: domjudge_root_pass
      CONTAINER_TIMEZONE: Asia/Seoul

      PHP_MAX_CHILDREN: 80
    volumes:
      - domserver-data:/opt/domjudge/domserver/etc
      - domserver-submissions:/opt/domjudge/domserver/submissions

4. 서비스 실행 및 비밀번호 설정

1

서버 및 DB 구동

먼저 DB와 웹 서버를 실행합니다. 초기화에는 약 30초가 소요됩니다.

docker compose up -d mariadb domserver
2

Judgehost API 비밀번호 확인

Judgehost가 서버에 접속할 때 필요한 API 비밀번호를 확인합니다.

docker exec -it domjudge-domserver cat /opt/domjudge/domserver/etc/restapi.secret

💡 위 명령어로 출력된 내용 중 마지막의 랜덤 문자열을 복사하여 docker-compose.yml의 JUDGEDAEMON_PASSWORD 항목에 붙여넣으세요.

3

초기 관리자(admin) 계정 정보 확인

DOMjudge v9.0.0의 초기 관리자 아이디는 admin입니다.
비밀번호는 보안을 위해 설치 시 랜덤으로 생성되므로, 아래 명령어를 실행하여 생성된 비밀번호를 확인해야 합니다.

웹 UI(Jury Interface) 접속을 위한 랜덤 비밀번호 확인 명령어:

docker exec -it domjudge-domserver cat /opt/domjudge/domserver/etc/initial_admin_password.secret
4

전체 서비스 시작

비밀번호를 docker-compose.yml에 입력하였다면, 전체 서비스를 실행합니다. Judgehost까지 모든 서비스가 자동으로 기동됩니다.

docker compose up -d
docker compose logs

5. 최종 확인 및 개수 조정

🆔 DAEMON ID 중복 방지 안내

여러 개의 채점기를 동시에 돌릴 때는 각 컨테이너마다 고유한 DAEMON ID를 부여받아야 합니다. 이를 위해 docker-compose.yml에 직접 DAEMON ID를 작성한 것입니다. 한 번만 설정하면 재부팅해도 유지됩니다.

✅ 최종 확인 사항

  • docker compose logs -f 명령으로 각 채점기가 서로 다른 ID로 활성화되었는지 확인합니다.
  • DOMjudge 관리자 페이지(Jury Interface) → Judgehosts 메뉴에서 여러 개의 Judgehosts 항목이 'Enabled' 상태인지 확인합니다.
🔧 Judgehost 개수를 바꾸고 싶다면 먼저 docker compose down 명령으로 모든 도커 서비스를 중단합니다. 이후 docker-compose.yml 파일을 수정한 뒤 docker compose up -d를 재실행하면 됩니다.
