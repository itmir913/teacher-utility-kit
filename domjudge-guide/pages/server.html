리눅스 서버 구성 및 설치

1. 서버 사양 및 OS 준비

본 권장 사양은 2025 ICPC Korea 대회 채점 환경(참고: 2025 ICPC 공지사항)을 기준으로 구성되었습니다.

  • OS: Ubuntu Server 24.04 LTS (신규 설치 권장)
  • CPU: 12 ~ 16 Cores (최소 8코어 이상)
  • RAM: 32 GB 이상
  • SSD: 256 GB 이상
  • 네트워크: 고정 IP 할당

💡 서버 하드웨어 구성 가이드 (Server Specification)

ICPC 공식 채점 환경(i7-11700K, 8코어/16스레드 기준)을 고려할 때, 최소 8코어(16스레드) 이상의 CPU로 구성하는 것을 강력히 권장합니다. 대회 중 발생하는 대량의 동시 컴파일(Concurrent Compilation)과 채점(Judging) 작업을 안정적으로 병렬 처리하기 위해서는 코어당 클럭 성능과 스레드 확보가 필수적이며, 이는 채점 서버의 응답 속도와 직결됩니다.

2. 시스템 업데이트 및 Docker 설치

서버 모니터링 및 성능 제어 도구를 설치하고, Docker 엔진을 구성합니다.

# 패키지 업데이트 및 유틸리티 설치
sudo apt update && sudo apt upgrade -y
sudo apt install -y htop cpufrequtils curl openssh-server

# 도커 공식 설치 스크립트 실행 및 사용자 권한 부여
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker $USER
newgrp docker

3. SSH 포트 설정

무차별 대입 공격(Brute-force)을 방지하기 위해 기본 SSH 포트(22)를 변경합니다.

설정 단계

  1. 파일 열기: sudo nano /etc/ssh/sshd_config
  2. 설정 변경: Port 22 부분을 찾아 원하는 포트번호(예: 22222)로 수정 후 주석(#) 제거
  3. 저장 및 종료: Ctrl + O → Enter → Ctrl + X
  4. 서비스 재시작: sudo systemctl restart ssh
# 설정 확인 명령어
sudo systemctl status ssh
ss -antp | grep 22222

4. 시스템 시간대 변경

타임존을 한국 시간(Asia/Seoul)으로 설정합니다.

# 타임존 설정
sudo timedatectl set-timezone Asia/Seoul && date

5. 스왑 메모리 및 CPU 성능 모드 설정

대량의 제출을 처리하기 위해 가상 메모리를 확보하고 CPU 클럭을 고정합니다.

# 스왑 파일 생성 (16GB)
sudo fallocate -l 16G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

# CPU 성능 모드 설정
echo 'GOVERNOR="performance"' | sudo tee /etc/default/cpufrequtils
sudo systemctl restart cpufrequtils
