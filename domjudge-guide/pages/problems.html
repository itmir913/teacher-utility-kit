문제 데이터 및 백업 관리

⚠ 문제 패키징 주의사항

DOMjudge는 표준 ICPC 문제 포맷(.zip)을 준수합니다. 각 패키지에는 반드시 domjudge-problem.ini 파일과 data/ 폴더(secret, sample 등)가 포함되어야 합니다.

1. 문제 생성 및 업로드

Jury Interface에서 문제 관리를 체계적으로 수행합니다.

  • Jury Interface: Problems 메뉴 → Add new problem 클릭.
  • ZIP 업로드: 문제 설명(PDF), 입력 파일(in), 정답 파일(out)이 포함된 패키지를 업로드합니다.
  • 설정 확인: 시간 제한(Time Limit) 및 메모리 제한이 적절한지 반드시 확인하십시오.

2. 테스트 케이스 관리 및 검증

채점의 정확성을 위해 테스트 케이스 구성과 검증은 필수입니다.

  • 데이터 분리: data/sample(공개용)과 data/secret(비공개 채점용) 폴더로 명확히 분리합니다.
  • 검증(Validation): 업로드 직후 'Check' 버튼을 눌러 제출한 샘플 파일이 정답으로 처리되는지 테스트합니다.
  • Diff 확인: 출력이 일치하지 않는 경우, Compare 스크립트(default, float 등)가 적절한지 설정에서 확인하세요.

3. 데이터베이스 백업

예기치 못한 서버 중단에 대비하여 주기적으로 DB를 백업하면 좋습니다.

# 현재 시간을 포함한 DB 덤프 백업
docker exec domjudge-mariadb mysqldump \
  -u domjudge -pdomjudge_pass domjudge \
  > backup_$(date +%H%M).sql

백업된 .sql 파일은 별도의 외부 저장소나 클라우드에 보관하는 것을 권장합니다.
