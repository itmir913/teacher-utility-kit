문제 데이터 및 백업 관리

⚠ 문제 패키징 주의사항

DOMjudge는 표준 ICPC 문제 포맷(.zip)을 준수합니다. 각 패키지에는 domjudge-problem.ini와 데이터 파일들이 포함되어야 합니다.

1. 실시간 모니터링

대회 중 Jury Interface 상단의 Judging Lag을 주시하십시오.

  • 30초 미만: 정상 운영 중
  • 1분 이상: 채점기 확장(Scale up) 필요
  • 무한 대기: Judgehost 컨테이너 상태 확인 필요

2. 데이터베이스 백업

예기치 못한 서버 중단에 대비하여 주기적으로 DB를 백업하면 좋습니다.

# 현재 시간을 포함한 DB 덤프 백업
docker exec domjudge-mariadb mysqldump \
  -u domjudge -pdomjudge_pass domjudge \
  > backup_$(date +%H%M).sql

백업된 .sql 파일은 별도의 외부 저장소나 클라우드에 보관하는 것을 권장합니다.
