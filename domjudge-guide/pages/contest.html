DOMjudge 대회 통합 운영 매뉴얼

DOMjudge 설치 이후 대회를 세팅하고, 운영하며, 종료 후 마무리하기까지의 전체 워크플로우를 안내합니다. 공식 매뉴얼과 병행하여 참고해주세요.

⚙️ Step 1. 대회 준비 및 시스템 설정 (Admin)

0. 운영진 권한 구분

DOMjudge는 아래 네 가지 역할을 제공합니다. 감독 교사에게는 jury 권한을 부여하는 것을 권장합니다.

권한 역할
admin 전체 시스템 관리 (모든 설정 접근 가능)
jury 스코어보드 + 제출 현황 열람, Clarification 답변 — 감독 교사용 권장
balloon 풍선 배달 담당 (정답 팀 추적, 선택적 운영)
team 일반 참가자 (문제 열람 및 코드 제출)
1. 대회(Contest) 생성 및 활성화

관리자 계정('Admin' → 'Contests')에서 대회를 생성하고 주요 일정을 설정합니다.

  • Activate: 대회 정보(이름 등)가 노출되기 시작하는 시간
  • Start: 실제 문제 열람 및 코드 제출이 가능해지는 시간
  • Freeze: 순위 동결 시작 시간 (종료 30분 전 권장)
  • End: 대회 종료 및 제출이 차단되는 시간
  • Public: 외부에서 스코어보드 공개 여부
⚠ 주의: Start 시간을 변경할 경우 Freeze, End 시간도 반드시 함께 조정하세요.
2. 팀 및 계정 생성

소수의 팀은 UI에서 직접 생성할 수 있지만, 팀이 많을 경우 TSV 파일 일괄 등록을 권장합니다. 자세한 방법은 아래 TSV 등록 절차를 참고하세요.

✓ Check: 팀이 올바른 카테고리 및 소속(Affiliation)에 정확히 매칭되었는지 최종 확인하세요.
3. 문제(Problems) 추가 및 라벨 지정

문제 ZIP 패키지 제작 방법은 앞의 문제(Problem) 준비 페이지를 참고하세요. 준비된 패키지를 'Admin' → 'Problems'에서 업로드한 뒤, 'Admin' → 'Contests' → 해당 대회 → Problems 탭에서 대회에 연결하고 Short name(라벨)을 지정합니다.

라벨을 a, b, c 순으로 지정하면 스코어보드에 A, B, C로 표시됩니다.
4. Judgehost(채점기) 연결 확인

'Admin' → 'Judgehosts' 메뉴에서 확인합니다. 학생이 제출한 코드가 자동으로 채점될 수 있도록 채점 서버가 정상적으로 연결되어 활성화 상태인지 점검합니다. Judgehost가 없으면 채점이 불가능하므로 대회 전 반드시 확인하세요.

🐍 Python 언어 Time factor 설정

Python은 C/C++에 비해 실행 속도가 느리므로 시간제한에 배수를 적용해 불이익을 방지합니다.

  1. Admin → Languages → Python 항목 클릭
  2. Time factor 필드에 1.5 입력 후 저장
예: 문제 시간제한이 2초인 경우 → Python 참가자에게는 자동으로 3초가 적용됩니다.

📋 대회 시작 전, 운영 필수 체크리스트

  • 🧊 점수판 동결 (Freeze): 대회 종료 30분 전에 순위를 숨겨 긴장감을 높일 시간을 설정했는지 확인합니다. Unfreeze는 시상식 직전 수동으로 실행하면 최종 순위가 한꺼번에 공개되어 극적인 효과를 연출할 수 있습니다.
  • ⏱️ 패널티 규칙: 오답 1회당 패널티 20분 적용 여부와 순위 산정 방식을 확인합니다. 순위는 ① 정답 문제 수 → ② 패널티 합계(정답 처리된 문제의 제출 시각(분) + 오답 횟수 × 20분) 순으로 결정됩니다.

📄 TSV 파일로 팀/계정 일괄 등록

팀이 많을 경우 TSV 파일을 사용하면 Admin → Import/Export에서 한 번에 등록할 수 있습니다. 아래 순서를 반드시 지켜야 합니다.

⚠ TSV 작성 시 주의사항

  • 인코딩: 반드시 UTF-8 — 한글 팀명이 포함된 경우 필수. 구글 스프레드시트 사용을 권장하며, 엑셀 사용 시 "다른 이름으로 저장 → CSV UTF-8"로 명시적 저장 필요.
  • 팀 이름 규칙: 한국어 허용. 공백은 언더바(_)로 대체 (예: 서울고_최강팀).
  • 등록 순서: teams.tsv를 먼저 Import한 뒤 accounts.tsv를 Import해야 합니다. 순서가 바뀌면 계정과 팀이 매칭되지 않습니다.
  • 이름 일치: accounts.tsv의 팀 이름이 teams.tsv의 팀 이름과 완전히 동일해야 합니다.

teams.tsv 형식

카테고리 ID는 Admin → Teams → Categories에서 "Participants" 항목의 ID를 확인하여 입력합니다.

File_Version	1
1	서울고_최강팀	4	서울고등학교
2	부산고_정복팀	4	부산고등학교

형식: [팀번호]  [팀이름]  [카테고리ID]  [소속학교]

accounts.tsv 형식

아이디와 비밀번호는 학생들에게 사전에 안내합니다.

File_Version	1
seoul01	pass1234	team	서울고_최강팀
busan01	pass1234	team	부산고_정복팀

형식: [아이디]  [비밀번호]  team  [팀이름]

등록 순서 (순서 중요)

  1. Admin → Import/Export → Teams 탭에서 teams.tsv 업로드
  2. Admin → Import/Export → Accounts 탭에서 accounts.tsv 업로드
  3. Admin → Teams에서 각 팀의 카테고리와 소속이 올바르게 등록되었는지 확인

🧪 데모 대회 운영

본 대회 전에 별도 Contest를 생성하여 참가자들이 시스템에 익숙해질 수 있도록 연습 시간을 제공합니다.

📝
연습 문제 연결

Hello World, 두 수의 합 등 간단한 문제 1~2개를 별도 Contest에 연결합니다. 본 대회 문제는 포함하지 않습니다.

👥
기존 계정 그대로 사용

데모 대회에서도 본 대회용 팀 계정을 그대로 사용합니다. 별도 계정 생성이 필요 없습니다.

⏰
여유 있게 운영

Freeze 없이 여유 있게 운영합니다. 데모 종료 후 본 대회 Start 시간을 실시간으로 조정하여 시작합니다.

💡 팁: 데모 대회 중 참가자들이 제출까지 성공적으로 완료하는지 확인하고, 네트워크나 계정 문제를 미리 해결하세요.

👨‍💻 Step 2. 대회 진행 및 학생 참여 가이드

학생들은 Team Member 역할을 통해 로그인하고 대회를 치릅니다. 관리자(Jury)는 대회가 진행되는 동안 시스템을 모니터링해야 합니다.

1. 로그인 및 문제 열람

학생은 부여받은 계정으로 접속하여 'Problemset' 메뉴에서 문제를 확인합니다.

2. 코드 작성 및 제출

로컬 환경에서 코드를 작성한 후, 'Submit' 버튼을 눌러 소스 코드를 업로드합니다.

3. 결과 확인 (Scoreboard)

채점 결과는 실시간으로 반환되며, 스코어보드를 통해 자신의 순위와 결과를 확인합니다.

Jury Task
4. 질의응답 (Clarifications) 처리

관리자는 대회 중 발생하는 모호한 점이나 오류 등에 대한 학생들의 질문(Clarifications 큐)을 실시간으로 모니터링하고 답변해야 합니다. 문제 오류 발견 시 운영진이 먼저 전체 공지로 발송할 수 있습니다.

🛠️ Step 3. 대회 종료 후 사후 관리 (Admin)

🔍
1. 채점 결과 리뷰

모든 문제의 채점(Judgment) 결과를 검토합니다. 서버 오류나 테스트 케이스 이상으로 잘못 채점된 건이 없는지 확인하고 필요시 재채점(Rejudge)을 진행합니다.

🏆
2. 리더보드 정리 (Unfreeze)

시상식 직전 Unfreeze를 실행하면 동결되었던 최종 순위가 한꺼번에 공개됩니다. 이 순간을 시상식 하이라이트로 활용할 수 있습니다.

🗄️
3. 데이터 백업 및 보관

모든 문제 셋, 제출된 소스 코드, 최종 스코어보드 등은 대회 종료 후 아카이빙하여 추후 참고 자료나 감사 용도로 보관합니다.

📊 시상 통계 추출

대회 종료 후 운영진 PC에서 내부망으로 DOMjudge REST API를 호출하면 제출 기록 전체를 수집할 수 있습니다. Python 스크립트로 데이터를 가공하여 Excel 시상 자료를 자동 생성합니다. DOMjudge 서버의 내부망 IP만 있으면 실행 가능합니다.

🥇 일반 시상 항목

  • •종합 1~3등 — 정답 수 + 패널티 합계 기준
  • •학교별 최고 순위 팀 — 모든 참가 학교 시상 가능
  • •학교별 총 정답 수 1위 — 소속 팀 정답 수 합산

🎨 창의 시상 항목

  • 🏆끈기상 — 오답을 가장 많이 받고도 결국 정답을 낸 팀
  • 🔥열정상 — 정답 0개지만 제출을 가장 많이 한 팀
  • ⚡선빵상 — 대회 시작 후 가장 빨리 첫 정답을 낸 팀
  • 🩸퍼스트 블러드 — 문제별 전국 최초 정답 팀
  • 🎭극적역전상 — 마감 1분 안에 정답을 낸 팀
  • 💎완벽주의상 — 단 한 번의 제출로 정답을 낸 문제가 가장 많은 팀
  • 🦄희귀템상 — 해당 팀만 유일하게 푼 문제가 있는 팀
  • 😭최다고난상 — 제출 횟수 대비 정답률이 가장 낮은 팀
