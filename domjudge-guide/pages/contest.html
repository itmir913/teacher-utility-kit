대회 운영 및 시스템 최적화

1. 대회(Contest) 활성화

관리자(Jury) 인터페이스에서 대회를 생성하고 시간을 설정합니다.

  • Activate: 대회 정보 노출 시작 시간
  • Start: 실제 문제 열람 및 제출 가능 시간
  • End: 대회 종료 및 제출 차단 시간

2. 채점기(Judgehost) 성능 확장

동시 제출이 많은 대규모 대회(100팀 이상)의 경우 채점기 컨테이너를 확장합니다.

# 채점기를 12개 컨테이너로 확장 (CPU 코어 수에 맞춰 조절)
docker compose up -d --scale judgehost=12

* 락(Lock) 파일 에러 발생 시 별도 정리 스크립트를 실행하십시오.

3. PHP 메모리 최적화

대용량 데이터 처리를 위해 PHP 설정을 변경해야 할 수 있습니다.

memory_limit = 512M
upload_max_filesize = 100M
post_max_size = 100M
