1. 데이터베이스 백업 및 복원

서버 장애나 설정 오류 발생 시를 대비해 주기적으로 백업하고, 필요 시 복원합니다. 백업 파일은 외부 저장소나 USB에 보관하세요.

백업

docker exec domjudge-mariadb mysqldump \
  -u domjudge -pdomjudge_pass domjudge \
  > backup_$(date +%H%M).sql

복원

docker compose stop domserver
docker exec -i domjudge-mariadb mysql \
  -u domjudge -pdomjudge_pass domjudge \
  < backup_HHMM.sql
docker compose start domserver
⚠ 주의: 복원 전 domserver를 중단해야 진행 중인 채점과 충돌이 발생하지 않습니다. 복원 후 스코어보드와 제출 내역이 백업 시점으로 롤백됩니다.

3. Judging Lag 대응 절차

Judging Lag 기준(30초/1분/무한)은 스트레스 테스트 페이지를 참고하세요. 아래는 각 상황별 실제 대응 방법입니다.

1분 이상 — 채점기 확장 
docker compose up -d --scale judgehost=$(($(nproc) > 5 ? $(nproc) - 4 : 1))
무한 대기 — Judgehost 재시작 
docker compose restart judgehost

재시작 후에도 복구되지 않으면 아래 섹션 4의 락 정리 스크립트를 실행하세요.
