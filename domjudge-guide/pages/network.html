네트워크 및 보안 설정

내부 네트워크

서버의 고정 IP 할당 및 내부망 통신 확인

외부 접속

80(HTTP), 443(HTTPS) 포트 개방 필수

1. 방화벽(UFW) 설정

서비스 운영에 필요한 최소한의 포트만 개방합니다.

# 기본 방화벽 규칙 설정
sudo ufw allow 22222/tcp  # 변경된 SSH 포트
sudo ufw allow 80/tcp     # HTTP
sudo ufw allow 443/tcp    # HTTPS
sudo ufw enable

2. Nginx Proxy Manager (SSL)

도메인 연결 및 Let's Encrypt 무료 인증서 적용을 위한 리버스 프록시 설정입니다.

1

Proxy Host 추가: 도메인 주소와 내부 IP:8080 연결

2

SSL 적용: 'Request a new SSL Certificate' 선택

3

Websockets Support: 반드시 활성화 (대시보드 실시간 업데이트용)
