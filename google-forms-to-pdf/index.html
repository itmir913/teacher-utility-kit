사용 방법

4단계만 따라하면 Google Forms 결과를 PDF로 변환할 수 있습니다.

01

CSV 파일 업로드

Google Forms에서 응답 결과를 CSV로 내려받아 데이터 업로드 탭으로 끌어다 놓으세요. 헤더를 자동으로 인식해 JSON으로 변환합니다.

구글 설문지 → 응답 → CSV 다운로드
02

템플릿 선택

템플릿 설정 탭에서 기본 제공 템플릿을 선택하거나 직접 HTML 템플릿을 업로드할 수 있습니다. {{field_name}} 형태로 필드를 치환합니다.

{{이름}} {{학번}} {{답변}}
03

미리보기 확인

미리보기 탭에서 각 응답이 템플릿과 합쳐진 결과를 확인합니다. 설문자별로 카드 형태로 표시되며 페이지 단위 구분도 볼 수 있습니다.

총 N개 응답 · 페이지별 분리 확인
04

PDF 출력

PDF 출력 탭에서 "PDF 인쇄" 버튼을 누르면 A4 기준으로 최적화된 인쇄 화면이 열립니다. 브라우저의 PDF 저장 기능을 사용하세요.

Ctrl+P → PDF로 저장
💡
