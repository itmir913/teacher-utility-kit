사용 방법

4단계로 Google Forms 응답을 PDF로 변환하세요.

01

CSV 파일 업로드

Google Forms에서 응답을 CSV로 다운로드한 후 데이터 업로드 탭으로 끌어다 놓으세요.

구글 설문지 → 응답 → CSV 다운로드
02

템플릿 선택

템플릿 설정 탭에서 기본 제공 템플릿을 고르거나 직접 HTML을 편집하세요. {{필드명}} 형태로 CSV 열을 삽입합니다.

{{이름}} {{학번}} {{답변}}
03

미리보기 확인

미리보기 탭의 「렌더링」 버튼을 누르면 각 응답이 카드 형태로 표시됩니다.

응답별 카드 · 페이지 단위 확인
04

PDF 출력

PDF 출력 탭에서 「PDF 인쇄」 버튼을 누르면 브라우저 인쇄 대화상자가 열립니다. 대상을 「PDF로 저장」으로 선택하세요.

Ctrl+P → PDF로 저장
🔒
