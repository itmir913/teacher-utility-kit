# Teacher Utility Kit

> **선생님들의 수업과 행정 업무 효율을 높여드리기 위한 교육용 도구 모음입니다.**

🔗 **공식 사이트 접속**: [https://luminousky.com/teacher-utility-kit/](https://luminousky.com/teacher-utility-kit/)

본 레포지토리는 교사를 위해 개발된 다양한 웹 도구 및 애플리케이션의 소스코드를 담고 있습니다. 정보 교과 수업 자료부터 학교 업무 자동화 프로그램까지, 교육 현장에서의 실질적인 편의를 최우선으로 고려하여 제작되었습니다.

---

## 🛠️ 포함된 주요 도구

이 레포지토리에는 다음과 같은 하위 프로젝트들이 포함되어 있습니다:

### 1. 정보 교과 수업용
* **정보·컴퓨터 교과 강의 자료**: CS 개념 시각화 교구
* **코드 학습지 생성기**: 인쇄 가능한 프로그래밍 학습지 제작
* **DOMjudge 서버 구축 가이드**: 교내 프로그래밍 대회나 코딩 테스트를 위한 자체 자동 채점 서버(DOMjudge) 구축 가이드

### 2. 학교 업무 자동화
* **All-in-One 학교생활기록부 에디터**: 학생 등록부터 영역 구성, 활동 생성, 생기부 작성, 나이스(NEIS) 내보내기까지 지원하는 에디터
* **학교생활기록부 일괄 점검 프로그램**: Excel/PDF 파일을 분석하여 키워드 강조 및 북마크 자동 생성
* **모의고사 성적 분석 시스템**: 모의고사 데이터 시각화 및 리포트 자동 생성
* **진학 상담 프로그램 자동 재시작 배치파일**: 대교협 상담 프로그램 서버 장애 대비 자동 재시작 배치파일

### 3. 기타 유틸리티
* **선생님 실시간 호출 시스템**: 교무실 방문 시 교사에게 실시간 호출 신호를 보내는 시스템
* **QRCode 등록 시스템**: 다수의 QRCode를 연속 스캔하여 엑셀 파일로 저장
